# 0012. 走っているジョブに2つの見方を用意する

- Status: Accepted
- Date: 2026-08-14

## Context

spindle から要件が来た（`remote-claude-terminal-streaming.md`）。**走っているジョブを、
開いたままの端末を眺めるように見たい**。終わってから報告を読むのではなく、
続行させるかどうかを決めながら見たい。

装飾ではない。実際に不具合が起きた3回、答えは出力の中にしか無かった:

- dev server を立てて curl する動作を20分繰り返した → 手でログを開くまで分からなかった
- `install` が `ECONNRESET` で落ちた → 出力からしか読めない
- 4分半沈黙した → 動いているのか詰まっているのか、最後に何を言ったかでしか判断できない

既存の `getLogs` では届かない。返すのは `LogLine { seq, ts, stream, line }` で、
**すでに行に割られ、バイトは失われている**。2秒間隔のポーリングで届くのは
「行の山」であって「起きていること」ではない。

## Decision

**2つの見方を別々に持つ。** 片方に寄せない。

| | 答える問い | 形 |
|---|---|---|
| `getLogs` | **どこまで進んだか** | 行。`seq` / `stream` / step marker |
| `/jobs/:id/output` と `/output/stream` | **いま何が起きているか** | バイト。行に割らず、切り詰めない |

runner は `log.ndjson` の隣に `output.raw` を書く。前者は解釈のための構造、
後者は端末が見せたはずのもの。step marker（`▶` / `✔`）は両方に入る —
端末を見ている人が「この出力はどの step のものか」を知る唯一の手段だから。

**agent の構造化イベントは `output.raw` に入れない。** `claude -p` の stdout は
NDJSON で、2秒のローカル実行だけで 35KB になる。それを端末に流すと
「いま何が起きているか」への答えが**翻訳済みの行より悪くなる**（Worker が
`· Read acp.ts` に翻訳している）。代わりに runner が定期的に
`⋯ claude-code still running (94s, 37 agent events)` を出す。件数は解釈ではない。

**オフセットはバイト。返すのは「見せた位置」であって「読んだ位置」ではない。**
これが伏せ字の設計を決めた。行の世界には無かった問題がある —
チャンク境界が秘密の真ん中に落ちると、どちらの断片も一致しない。
そして送ったバイトは取り返せない。

したがって「まだ続きが来るなら末尾 256 バイトを出さず、次のオフセットもそこまでにする」。
読者は次の読み取りでそれを回収し、その時には残りが届いている。
状態を持たずに、境界跨ぎを防げる。

## Alternatives

**`streamProcessLogs` でプラットフォームから直接流す。** SDK にあるが、
runner は自分の stdout に何も書かない（子の出力は捕まえてファイルに書く）ので、
流れるものが無い。runner に生エコーさせると、オフセットが取れず（この API に
offset が無い）、複数読者のファンアウトも Worker 側で作る必要がある。
ファイルのオフセット tail は R2（再開）と R6（複数読者）を構造的に満たす。

**WebSocket。** 双方向を必要としていない。R4 は入力路を**作らないでほしい**と
明示している。SSE なら受け側が `fetch` だけで済む。

**行のポーリング間隔を詰める。** 生存感は改善するが、行に割られている事実は変わらない。

## Consequences

- 走っているジョブの端末を、オフセット指定で再開しながら追える
- 終端は `end` イベントで status 付き。**切断と区別できる**（R5）。
  これが無いと、終わったジョブと落ちた接続が同じ絵になる
- **ANSI は来ない。** 子プロセスは `stdio: ['ignore','pipe','pipe']` で起動され、
  TTY が無いのでツールは色付けと再描画をやめる。届けるには PTY を張る必要があり、
  それは全ジョブの出力を変える（`log.ndjson` にも制御コードが入る）ので別の判断
- **コンテナが消えたジョブの端末は残らない。** 実行中だけ。
  解析済みのログはコンテナより長生きするが、これはしない。境界として明示する
- `output.raw` は 8MB で止まり、止まったことを自分で書く
